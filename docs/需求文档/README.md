# 春之声国际旅行社 · 落地页 Demo — 需求文档

> 版本：v1.0 · 日期：2026-09-10 · 状态：待评审

---

## 1. 项目背景

春之声国际旅行社（上海）有限公司 / Sound Of Spring International Travel Agency
(Shanghai) Ltd 是一家成立于杭州、深耕江南文化旅行的精品旅行社，家族两代人累计
50 余年本地旅游积淀，公司 20 年前独立运营，是 Wild China（全球 Top 12 旅行社）
的官方供应商。

本项目为其 **B 端 / C 端展示型落地页 Demo**，用于对外品牌展示、产品介绍与潜客
留资，定位为可独立部署的纯静态站点。

## 2. 项目目标

| 维度 | 目标 |
| ---- | ---- |
| 品牌 | 突出"江南文化 + 精品定制"调性，建立专业、可信赖、有温度的品牌形象 |
| 产品 | 清晰展示 4 大产品线（定制化 / 传统 / 亲子 / 文化体验），便于用户选择 |
| 转化 | 通过差异化留资表单，收集不同产品线对应的有效潜客信息 |
| 多语言 | 面向国际客源，默认英文，可切换俄语、简体中文 |
| 部署 | 纯静态站点，无后端依赖，便于托管到任意 CDN / 静态服务 |

## 3. 受众

- **C 端**：国内外中高端自由行 / 家庭 / 文化爱好者游客
- **B 端**：企业团建 / 会务会展 / 学校研学的采购方
- **渠道**：Wild China 等合作伙伴转介来的英文 / 俄文客户

## 4. 信息架构与导航

顶部固定 Tab（横向）：

```
公司介绍  |  产品介绍/选择  |  攻略  |  语言选择 ▾  |  联系我们
```

- 「公司介绍」：`index.html` — 公司主页 / Hero
- 「产品介绍/选择」：`products.html` — 4 大产品线 listing
- 「攻略」：`guides.html` — 旅行攻略合集
- 「语言选择」：右上角下拉，非独立页面，仅切换 i18n
- 「联系我们」：`contact.html` — 公司联系方式 + 通用咨询表单

## 5. 功能需求

### 5.1 主页 / 公司介绍（index.html）

| 区块 | 内容 |
| ---- | ---- |
| Hero | 公司 Logo + 中英文 Slogan + 杭州天际线大图 + CTA 按钮 |
| 关于我们 | 沿革、家族 50+ 年积淀、Wild China 供应商资质 |
| 公司愿景 | "分享杭州历史与故事给全世界的朋友" + 配图 |
| 业务板块 | 文化旅游、剧本团建、增效旅行、会务会展 四张卡片 |
| 核心数据 | 在地年数、服务客户数、定制路线数等 |
| 主要客户 | Logo 墙 |
| 底部 CTA | 跳转到产品 / 联系我们 |

### 5.2 产品介绍 / 选择页（products.html）

- 4 个产品分类卡片网格：
  1. **定制化 (Custom Travel)** — Private & Bespoke
  2. **传统 (Classic Tours)** — 经典路线、热门景点
  3. **亲子 (Family Trip)** — 亲子陪伴
  4. **文化体验 (Cultural Experience)** — 剧本游 + 博物馆 + DIY + 美食
- 卡片悬停动效，点击进入对应详情页
- 顶部产品筛选标签（可按类型切换）

### 5.3 产品详情页

四个独立详情页，每个包含：

| 区块 | 内容 |
| ---- | ---- |
| Hero | 产品大图 + 标题 + 副标题 |
| 产品介绍 | 富文本描述 + 配图 2~3 张 |
| 行程亮点 / 包含项 | 列表形式 |
| 客户信息留取 | 差异化表单（见 §5.4） |

详情页 URL：

- `product-custom.html`
- `product-traditional.html`
- `product-family.html`
- `product-culture.html`

### 5.4 留资表单（差异化）

| 产品 | 共有字段 | 差异化字段 |
| ---- | -------- | ---------- |
| 定制化 | 姓名、邮箱、手机、出发日期、人数 | **预算范围**（必填）、**兴趣主题**（多选：文化/美食/摄影/户外）、备注 |
| 传统 | 姓名、邮箱、手机、出发日期、人数 | **行程天数**（必填，1/2/3/5/7+ 天）、**出行方式**（跟团/半自助） |
| 亲子 | 姓名、邮箱、手机、出发日期、人数 | **孩子年龄**（必填，0-3/4-6/7-12/13-17）、**孩子数量**、**是否需要儿童餐** |
| 文化体验 | 姓名、邮箱、手机、出发日期、人数 | **感兴趣模块**（多选：剧本游/博物馆/DIY/美食）、**语言偏好**（中文讲解/英文讲解/俄文讲解） |

- 前端表单校验（必填、邮箱格式、手机格式）
- 提交后弹出成功提示（Demo 中不实际提交后端）

### 5.5 攻略页（guides.html）

- 卡片网格：杭州西湖、灵隐寺、龙井茶园、西溪湿地、宋城、河坊街 等 6~8 篇
- 每篇：封面图 + 标题 + 摘要 + 阅读时长
- 详细正文放在 `guides/<slug>.html`（Demo 中以占位卡片表示，点击展开或跳转静态页）

### 5.6 联系我们页（contact.html）

- 公司信息：Email / Mobile / Tel / WeChat / 地址
- 通用咨询表单（姓名 / 邮箱 / 留言）
- 嵌入一张杭州标志性景点图（雷峰塔日落）

### 5.7 多语言切换

- 三种语言：**English（默认）/ Русский / 简体中文**
- 切换方式：右上角下拉，切换后立即生效
- 偏好持久化到 `localStorage`
- 命名规范：HTML 节点上添加 `data-i18n="key"`，JS 字典统一管理

## 6. 内容需求

- 公司介绍 → 取自 `docs/春之声国际旅行社简介.pptx`（已提取）

## 7. 设计风格

| 项目 | 规格 |
| ---- | ---- |
| 整体色调 | **明亮色**：以暖米白 / 浅杏为主背景，搭配嫩绿（春）、朱砂红（点缀）、墨黑（文字） |
| 主色 | `#FAF7F2` 背景 / `#1F3A2E` 深绿（强调）/ `#C8553D` 朱砂红（点缀）/ `#2A2A2A` 文字 |
| 字体 | 标题：Playfair Display（英文衬线）/ 思源宋体（中文）；正文：Inter / 思源黑体 |
| 圆角 | 卡片 12~16px，按钮 24px（药丸状） |
| 阴影 | 轻微悬浮 `0 8px 24px rgba(0,0,0,.06)` |
| 响应式 | 桌面优先（≥ 1200px），兼容平板（≥ 768px），移动端（≥ 375px） |
| 图片 | 圆角处理 + 轻微饱和度提升，保持江南温润感 |

## 8. 非功能需求

- **纯静态**：无构建依赖（不使用任何框架），双击 `index.html` 或上传到任意静态服务即可运行
- **性能**：首屏 LCP < 2.5s（4G 模拟），所有图片走 `loading="lazy"`
- **可访问性**：语义化 HTML、键盘可达、对比度 ≥ AA、alt 必填
- **浏览器兼容**：Chrome / Safari / Edge 最近 2 个大版本
- **SEO**：每页 `<title>` / `<meta description>` / `og:` 标签齐全

## 9. 验收标准

- [ ] 5 个核心页面（公司介绍 / 产品 listing / 4 个详情 / 攻略 / 联系我们）均可访问且内容完整
- [ ] 顶部 Tab 在所有页面之间可正常跳转，高亮当前页
- [ ] 三个语言切换流畅，无遗漏文案（不要求逐字翻译到位，但关键区块不出现英文硬编码）
- [ ] 4 个详情页的留资表单字段差异化，且前端校验生效
- [ ] 整体色调明亮温暖，与"江南 / 春"主题契合
- [ ] 桌面与移动端均无横向滚动条，图片不溢出
- [ ] 任何页面、任何语言下，所有图片加载成功（无 404）

## 10. 范围之外（Out of Scope）

- 真实后端 / 留资数据上报（仅前端弹成功提示）
- 用户登录 / 注册 / 会员体系
- 在线支付 / 订单管理
- 后台管理 / CMS
- 多语言切换外的暗色模式
- SSR / SEO 深度优化
